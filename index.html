Subdomain takeover proof-of-concept

Hostname: mail.openssl.org

This page is served from an unaffiliated GitHub Pages repository. It demonstrates that mail.openssl.org resolves to GitHub Pages with no site configured, so any GitHub account can claim the hostname and serve arbitrary content (including over HTTPS, since a certificate has already been provisioned for it).

No malicious intent; content will be removed immediately after verification. This finding is being reported through the OpenSSL security process.
